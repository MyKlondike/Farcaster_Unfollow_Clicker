Unfollow Clicker (JavaScript Browser Automation)
🧠 Overview

This script automatically clicks on all visible “Unfollow” buttons on a webpage, waits 1 second between each click, then scrolls down the page and waits 3 seconds before continuing.
It repeats this process until no more “Unfollow” buttons are found.

⚙️ Features

Clicks all visible “Unfollow” buttons.

Waits 1 second between clicks.

Scrolls down after finishing each batch and waits 3 seconds.

Stops automatically when no buttons remain.
